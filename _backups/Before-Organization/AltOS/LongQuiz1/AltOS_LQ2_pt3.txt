Option: cp newfile1.txt backup*
Option: mv newfile1.txt backup

Question: Assuming "aos" directory is not empty, write the UNIX command that will delete the given directory.
Option: rm -r aos*
Option: rmdir aos
Option: del -r aos
Option: remove aos
Explanation: The rmdir command only removes empty directories; to delete a non-empty directory, rm -r (recursive delete) must be used.
