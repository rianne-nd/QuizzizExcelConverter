Question: What is the function of the Diffie-Hellman algorithm within the IPsec framework?
Option: guarantees message integrity
Option: allows peers to exchange shared keys*
Option: provides authentication
Option: provides strong data encryption
Explanation: Diffie-Hellman is a key exchange algorithm that allows two IPsec peers to establish a shared secret key over an insecure channel.
