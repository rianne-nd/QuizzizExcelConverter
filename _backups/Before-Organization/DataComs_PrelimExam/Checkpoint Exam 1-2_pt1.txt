Question: Which three statements describe features of the OSPF topology table? (Choose three.)
Option: It is a link-state database that represents the network topology.*
Option: Its contents are the result of running the SPF algorithm.
Option: When converged, all routers in an area have identical topology tables.*
Option: The topology table contains feasible successor routes.
Option: The table can be viewed via the show ip ospf database command.*
Explanation: The topology table on an OSPF router is a link-state database (LSDB) that lists information about all other routers in the network, and represents the network topology. All routers within an area have identical link-state databases, and the table can be viewed using the show ip ospf database command. The EIGRP topology table contains feasible successor routes. This concept is not used by OSPF. The SPF algorithm uses the LSDB to produce the unique routing table for each router which contains the lowest cost route entries for known networks.

Question: What does an OSPF area contain?
Option: routers that share the same router ID
Option: routers whose SPF trees are identical
Option: routers that have the same link-state information in their LSDBs*
Option: routers that share the same process ID
Explanation: An OSPF area contains one set of link-state information, although each router within the area will process that information individually to form its own SPF tree. OSPF process IDs are locally significant and are created by the administrator. Router IDs uniquely identify each router.

Question: What is used to facilitate hierarchical routing in OSPF?
Option: the use of multiple areas*
Option: frequent SPF calculations
Option: autosummarization
Option: the election of designated routers
Explanation: OSPF supports the concept of areas to prevent larger routing tables, excessive SPF calculations, and large LSDBs. Only routers within an area share link-state information. This allows OSPF to scale in a hierarchical fashion with all areas that connect to a backbone area.

Question: Which OSPF data structure is identical on all OSPF routers that share the same area?
Option: forwarding database
Option: link-state database*
Option: adjacency database
Option: routing table
Explanation: Regardless of which OSPF area a router resides in, the adjacency database, routing table, and forwarding database are unique for each router. The link-state database lists information about all other routers within an area and is identical across all OSPF routers participating in that area.

Question: Which step does an OSPF-enabled router take immediately after establishing an adjacency with another router?
Option: builds the topology table
Option: exchanges link-state advertisements*
Option: chooses the best path
Option: executes the SPF algorithm
Explanation: The OSPF operation steps are as follows: Establish neighbor adjacencies, Exchange link-state advertisements, Build the topology table, Execute the SPF algorithm, Choose the best route.
