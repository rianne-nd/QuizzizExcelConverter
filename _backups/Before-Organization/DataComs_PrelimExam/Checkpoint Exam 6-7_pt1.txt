Question: Which two statements accurately describe an advantage or a disadvantage when deploying NAT for IPv4 in a network? (Choose two.)
Option: NAT improves packet handling.
Option: NAT will impact negatively on switch performance.
Option: NAT causes routing tables to include more information.
Option: NAT provides a solution to slow down the IPv4 address depletion.*
Option: NAT introduces problems for some applications that require end-to-end connectivity.*
Explanation: NAT conserves public IPv4 addresses by allowing many private hosts to share a few public addresses, but it hides end-to-end addressing and can cause problems for applications that require end-to-end connectivity.

Option: Identify the participating interfaces as inside or outside interfaces.*

Question: What is a disadvantage of NAT?
Option: There is no end-to-end addressing.*
Option: The router does not need to alter the checksum of the IPv4 packets.
Option: The internal hosts have to use a single public IPv4 address for external communication.
Option: The costs of readdressing hosts can be significant for a publicly addressed network.
Explanation: NAT hides the original source and destination addresses, so end-to-end addressing and traceability are lost.
