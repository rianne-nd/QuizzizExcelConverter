Question: Assuming you are in g1 directory, delete game2 and gg3 in the upper directory using one line of code
Type: Fill-in-the-Blank
Answer: rm ../game2 ../gg3
Explanation: The ../ prefix references the parent directory, allowing you to delete game2 and gg3 from within g1.

Question: What is the command in MS DOS to change the file attribute (attribute: read only and hidden; filename: file.txt)
Type: Fill-in-the-Blank
Answer: attrib +r +h file.txt
Explanation: In MS-DOS, attrib +r +h file.txt sets both Read-Only (+r) and Hidden (+h) attributes on file.txt.
