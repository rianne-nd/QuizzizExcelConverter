Question: How can you set the default rwx permission to all users on every file which is created in the current shell?
Option: umask 666
Option: umask 777
Option: umask 000*
Option: umask 555
Explanation: umask 000 removes no permissions from the default creation mode; directories become rwxrwxrwx, while regular files still typically get rw-rw-rw- unless execute bits are added.
