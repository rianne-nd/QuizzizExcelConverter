Question: What will be the effect of chmod 701 when applied to file PASS.txt?
Option: r---w-r-x
Option: rw--wxr-x
Option: rwx-w-r-x
Option: rwx---x*
Explanation: Octal 701 gives the owner rwx, the group no permissions, and others execute-only permission.

Question: How do you get all files with on the 3rd place an r, g or i?
Option: ls '[rgi]*'
Option: ls '?3[rgi]*'
Option: ls ??[rgi]**
Option: ls [..i\*]
Explanation: Two question marks match any first two characters, [rgi] matches the third character as r, g, or i, and the trailing wildcard matches the rest.

Question: Which of the following file contains the encrypted password of the users?
Option: /etc/ghshadow
Option: /etc/passwd
Option: /etc/user.conf
Option: /etc/shadow*
Explanation: User password hashes are stored in /etc/shadow, which is readable only by privileged users.

Question: How can we find the process name from its process id?
Option: ps -p ProcessId*
Option: ps p- ProcessId
Option: pidof ProcessId
Option: ps p ProcessId
Explanation: The ps -p option selects the process by PID and displays information about it, including the process name.
