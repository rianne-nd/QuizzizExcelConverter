Question: A security policy requires all site-to-site traffic transmitted over the public internet to be fully encrypted to guarantee data confidentiality, as well as data integrity and origin authentication. Option: True
Option: False*

Question: An administrator is configuring Hashed Message Authentication Code (HMAC) parameters for an IPsec tunnel and must decide between MD5 and SHA to ensure packet integrity. Option: True
Option: False*
