Question: A network analyst is calculating the fixed and variable delay components for a voice stream traveling across an enterprise WAN link. Serialization delay represents the variable time a frame waits in memory queues before being transmitted, while queuing delay represents the fixed time required to transmit a frame onto the physical wire.
Option: True
Option: False*
Explanation: The definitions are swapped. Serialization delay is the fixed time required to transmit a frame onto the physical wire, while queuing delay is the variable time a frame waits in memory queues.
